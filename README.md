# HTTP Cats - Status Code Explorer 🐱

An interactive web application that helps users explore HTTP status codes through HTTP Cat illustrations.

## 📌 Project Overview

HTTP Cats provides cat images for different HTTP status codes.

This project allows users to:

1. Select an HTTP status code category.
2. View the available status codes in that category.
3. Select a specific status code.
4. View the status code, its meaning, and the corresponding HTTP Cat image.

## 🚀 Features

- Explore HTTP status codes by category.
- Supports 1xx, 2xx, 3xx, 4xx, and 5xx categories.
- Dynamically generates status-code buttons using JavaScript.
- Displays the meaning of the selected status code.
- Displays the corresponding HTTP Cat image.
- Responsive design for different screen sizes.
- Form validation for category selection.
- Clean and simple user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTTP Cats

## 🔗 API Used

HTTP Cats:

https://http.cat/

The application dynamically generates the image URL based on the selected HTTP status code.
